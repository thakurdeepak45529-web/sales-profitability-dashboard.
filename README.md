# Sales & Profitability Analysis Dashboard

## About This Project
This project is an interactive Excel dashboard designed to analyze sales and profitability performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- KPI Cards

## Key Features
- Sales and Profit Analysis
- KPI Cards for important business metrics
- Interactive Slicers for filtering data
- Category-wise Sales Analysis
- Region-wise Performance Analysis
- Sales Channel Analysis

## Project Objective
To convert raw sales data into meaningful insights and help businesses make better decisions.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Use the slicers to explore sales and profit performance.

## Skills Demonstrated
Excel Dashboard Design, Data Analysis, Pivot Tables, Data Visualization, and Interactive Reporting.
